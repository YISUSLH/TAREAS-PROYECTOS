PROYECTO: Actividad 2

Este proyecto está listo para abrirse en NetBeans como proyecto Maven.

PASOS PARA ABRIR EN NETBEANS:
1. Abre NetBeans.
2. Da clic en File > Open Project.
3. Selecciona la carpeta Actividad 2.
4. Abre el archivo Alumno.java.
5. Ejecuta el proyecto con Run Project o clic derecho sobre Alumno.java > Run File.

El programa calcula el promedio de cinco calificaciones y asigna una calificación final.
